| File | Digest | Interior | Palette |
| --- | --- | --- | --- |

| `pah.svg` | Thursday · PAH | Pulmonary-artery Y-tree | `#2367a6` + `#c05640` |

Hero SVGs keep two line weights (outline ~7, interior 2–5). `*-icon.svg` drops distal twigs so the 54px mail header stays readable.

PNG exports (`*-icon-{54,108,216}.png`, `*-512.png`) are generated by `python scripts/export_logos.py`.
